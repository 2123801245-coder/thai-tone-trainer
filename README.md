# 泰语声调识记工具

单文件网页：泰语声调规则查询（声母类别 × 活死音节 × 调号）、声调总表、声母类别全表、常见词声调、音高走势示意、自测（含听音辨声调）、错题重练与本设备历史错题。

音频用设备自带的泰语语音朗读，个别设备需先在系统设置里安装泰语语音。

## 部署

本仓库由 GitHub Pages 发布，访问地址为 https://2123801245-coder.github.io/thai-tone-trainer/ ，手机浏览器打开后可用“添加到主屏幕”装到主屏幕。
